# Retail Customer Churn & Retention Analysis

> **End-to-end predictive analytics pipeline** for identifying at-risk retail customers and prescribing targeted retention actions.

---

## Problem Statement

An e-commerce retailer is losing **18% of customers annually** to churn. The goal is to:
1. **Predict** which customers are likely to churn before they leave
2. **Explain** why they are at risk
3. **Segment** them into actionable cohorts with specific retention tactics
4. **Simulate** the ROI of targeted intervention campaigns

---

## Dataset

**Source:** Synthetic dataset generated to replicate real e-commerce churn patterns.

| Property | Value |
|----------|-------|
| Customers | 6,000 |
| Features | 20 (demographic, behavioral, transactional, service) |
| Churn Rate | ~18% |
| Missing Values | 2.5% (realistic) |

**Key features:**
- `Tenure`, `SatisfactionScore` (1-10), `Complain` (binary)
- `DaySinceLastOrder`, `OrderCount`, `OrderAmountHikeFromlastYear`
- `PreferredPaymentMode`, `PreferedOrderCat`, `CityTier`
- `HourSpendOnApp`, `NumberOfDeviceRegistered`, `CashbackAmount`

> The dataset is fully reproducible via `generate_data.py` with a fixed random seed (`np.random.seed(42)`).

---

## Reproducibility

```bash
# 1. Clone and setup
pip install -r requirements.txt

# 2. Generate the dataset
python generate_data.py

# 3. Run the full analysis
python churn_analysis.py
```

All outputs (charts + scored data) will appear in `outputs/` and `data/` respectively.

## Key Results

### Model Performance

| Model | AUC-ROC | Avg Precision | Recall (Churn) |
|-------|---------|---------------|----------------|
| **Random Forest** | **0.961** | **0.857** | **83%** |
| Logistic Regression | 0.951 | 0.840 | 88% |

**Production model:** Random Forest — best precision-recall balance and interpretable feature importance.

### Top Churn Drivers

1. **RiskScore** (engineered composite) — strongest predictor
2. **Complain** — customers who filed complaints churn at **54%** vs. **8%**
3. **Tenure** — 0-6 month customers: **31% churn**; drops to ~8% after 12 months
4. **SatisfactionScore** — score <=3: **58% churn**; score 9-10: **<1% churn**
5. **DaySinceLastOrder** — 31+ days: **32% churn**; 0-7 days: **14% churn**

### Customer Segmentation

| Segment | Count | Recommended Action |
|---------|-------|-------------------|
| Critical: Immediate Intervention | 686 | Personal outreach + retention offer |
| High Risk + Complaint: Escalate | 246 | Dedicated CS resolution + compensation |
| High Risk + New: Onboarding Fix | 269 | Redesign first-30-day journey |
| Dormant: Re-engagement | 481 | Win-back email + discount |
| Low Satisfaction: Service Recovery | 637 | Proactive service check-in |
| Stable: Loyalty Program | 3,653 | VIP perks, referrals, upsells |

### ROI Simulation

Targeting the **top 20%** of at-risk customers captures **~95% of all churners** — highly efficient marketing spend.
